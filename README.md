# Meshwark Driver 🚗

## Overview
Meshwark Driver is a Flutter-based mobile application for drivers, providing comprehensive ride management services.

## Features
- User authentication
- Driver profile management
- Ride tracking
- Account verification
- Intuitive UI

## Getting Started

### Prerequisites
- Flutter SDK
- Android Studio or VS Code
- Dart SDK

### Installation
1. Clone the repository
   ```
   git clone https://github.com/yourusername/meshwark_driver.git
   ```
2. Install dependencies
   ```
   flutter pub get
   ```
3. Run the app
   ```
   flutter run
   ```
